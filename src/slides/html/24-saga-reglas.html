02 · SAGA · Reglas de oro

Cuatro reglas para que una SAGA funcione

Compensar no es borrar

Es otra acción que deshace el efecto: cancelar el vuelo, liberar los créditos.

Orden inverso

Se compensa del último paso completado hacia el primero.

Idempotente

Compensar dos veces no debe hacer daño: puede reintentarse.

Estado visible

El usuario ve “procesando” o “cancelado”, nunca un lote a medias.

Herramientas: Azure Durable Functions · Temporal · Camunda · Eventuate Tram. Ninguna gana siempre (Dürr et al., 2022).
