04 · Diseño de esquemas de eventos

El tamaño del evento también es latencia

Pequeño

{ loteId, estado }

Viaja rápido y evoluciona fácil; el consumidor consulta el resto.

Grande y desnormalizado

{ lote, imágenes[], usuario }

Sin llamadas extra; más red y difícil de cambiar sin romper.

Event Storming para descubrir eventos, productores y consumidores.

Involucra a los consumidores antes de fijar el esquema.

Versiona: campos opcionales, schemaVersion y deprecación gradual.

Fuente: SD5 – Semana 5 (Elegir el diseño correcto de esquema; “Choosing the Correct Event Schema Design”, SpringerLink)
